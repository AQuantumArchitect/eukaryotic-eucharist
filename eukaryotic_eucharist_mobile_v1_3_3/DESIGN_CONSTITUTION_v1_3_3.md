# Design Constitution v1.3.3 — Predator Flow and Eucharist Balance

This branch preserves the v1.3 strict graph rule: every function is an organelle, every capacity is graph-derived, and bodies attack only through organs.

## Flow law

Resource conversion is curved. Full tanks create faster volume flow but lower efficiency; low tanks are slow but frugal. Anaerobic Processors should let an idle, biomass-fed bacterium recharge ATP, but motion must be expensive enough that pre-mitochondrial play alternates between moving, feeding, and charging.

## Feeding law

Feeding must stay deliberate. Basal Membrane Intake Pores are slow. Cytostome Bloom extends range and flow but must remain stack-worthy: one cytostome should help, not solve all ingestion forever.

## Predator law

Predators must commit to overlap. Rasping is an overlap organ, so predator AI should crawl onto prey instead of orbiting at the rim. Predators receive enough Anaerobic Processors and storage to keep the rupture layer active, but toxin accumulation remains a possible life-cycle failure.

## Rasping law

Rasping costs ATP once per body per tick, not once per target. Its cost scales with body size: small bacteria can use rasping efficiently; large bodies should prefer impact organs such as Lance Bristles.

## Lance law

Lances are impact organs, not beams. Slow contact should do little damage. Fast movement and dash-speed impacts should matter. Multiple lances still stack, but each lance should feel like one spike, not a screen-clearing laser.

## Eucharist law

Mitochondrial Eucharist no longer requires oxygen tolerance. It requires a deep DNA record. DNA can be physically carried before mitochondria if the body has a DNA Memory Vesicle, but Tier 3 interpretation remains post-Eucharist.
