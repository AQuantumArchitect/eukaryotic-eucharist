# Design Constitution v1.2.0 Amendment

## ATP is the hard action gate

ATP is the foundational action token. If a body has no ATP, it cannot move, feed, repair, rasp, dash, launch toxins, or vent clouds. If it has no ATP and no biomass to ferment, it dies.

## Fermentation is an organelle flow

A Fermentation Matrix is not an abstract upgrade. It is an organ that converts biomass into ATP and toxin waste. Starter cells have one. Buying another matrix adds another identical flow.

## Bodies do not attack; organs attack

The starter has no attack. Rasping Lamella, Lance Bristle, Toxic Launcher, and Toxin Cloud are explicit organs. Weapon behavior must come from those organs.

## Toxic Launcher is not edible toxin

The Toxic Launcher fires damaging projectiles that burst into chemical hazard fields. These hazards are not resource fields and should not be eaten by NPCs.

## Matter storage is small by default

Early cells have tiny biomass and lipid tanks. Storage capacity must be embodied through storage organelles.

## Vacuoles are structures, not currency

Vacuoles are no longer collectible resources. They remain meaningful as organelles: Oxygen Vacuole, Buoyancy Vacuole, Dash Vacuole, and storage structures.

## Yuki exchanges are one-output restocks

Tier 1 exchange buttons should feel like restocking tanks: each button outputs one resource/service type, with mixed costs allowed but not mixed output bundles.
