Graph-strict design

The rule all of this follows: every function is an organelle, and bodies act only through organs. There are no hidden stats. Movement, feeding, storage, attacks and oxygen tolerance all come from parts a body actually carries, so the player, the algae, the scavengers and the predators all run on the same rules. The kernel (src/graph_kernel.mjs) owns the whole simulation (fields, bodies, metabolism, death bloom, the shop), and index.html only renders it. Kernel smoke tests run headless in Node.

  • Plain ES modules, no build step, no dependencies. It runs from any static file server.
  • Resources are fields in the water, not coins. Death blooms into terrain that feeds the column.
  • A Godot 4.5 port renders the same JS kernel through JavaScriptBridge, as an engine-integration experiment.
Controls: WASD / arrows to swim, F or right mouse to feed, E for Yuki, O for the hull graph. Touch controls appear on phones. · GitHub
