# Eukaryotic Eucharist soundtrack

Original twelve-track score by **Paul Spooner** (`dudecon`), produced with Suno and contributed by
Paul for Eukaryotic Eucharist.

The source contribution is preserved in repository history as commit `fbf504e`, authored by Paul.
The music player loads one MP3 at a time after an explicit player gesture; it never autoplays.
