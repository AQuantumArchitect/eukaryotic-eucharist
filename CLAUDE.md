# Claude Code

Claude Code on Luke's laptop, Fenrir, playtests this repository: automated kernel tests and agentic playthroughs.

## Human playtest handoff

When you judge the game ready for a release cut and a human playtest, open a GitHub issue labelled `ready-for-human-playtest`. The issue must include:

- the build or commit SHA
- how to run it (browser/html channel)
- the evidence (tests and playthrough results)
- the estimated time to beat (about 1 hour)
- the known issues

Then stop and wait for Luke's sign-off in that issue before any release. Do not tag a release and do not push to itch.
