# Design Constitution v1.1.1 Amendment

## ATP is the cell energy token

The game uses ATP as the player-facing energy name. Internally, code may still use `energy` as the resource key for simplicity, but all UI and design language should call it ATP.

## No starter acid

The starter cell has no attack action. It survives through field feeding, flight, opportunistic scavenging, and Yuki exchange.

Acid chemistry is late Tier 2. It requires Toxin Sac and should not negate the early toxin/anaerobic scavenger game.

## Spawn into a mature ecology

The game should begin with the trophic pump already active. Surface algae, falling biomass, predators, scavengers, and rupture fields are already present. The player should not wait for ecology to become interesting.

## Bodies still do not attack by default

Damage comes from organs: rasping lamella, lance bristle, toxin sac/acid, toxin cloud, predator morphology. Basic body overlap creates pressure and displacement, not generic hero damage.
